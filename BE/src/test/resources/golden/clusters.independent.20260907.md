## 2. 라벨·분할·봉인

현재 표본의 예측을 읽기 전에 모든 제목과 요약 발췌를 검토하고, 모호하거나 여러 기사가
포함된 사건은 본문 전체 또는 추가 발췌로 확인했다. 모든 기사 본문을 완독한 것은 아니다.
Java 입력에는 제목·요약·본문을 자르지 않고 원형대로 유지했다.

같은 구체적 발표·행동·발생 사건을 묶고, 같은 기업·산업·전시회만으로는 묶지 않았다.
같은 보고서의 관점 차이는 한 사건, 서로 다른 보고서·제품 발표·별도 후속 행동은 다른 사건이다.
하나의 사건을 특정하기 어려운 종합 기사·칼럼은 개별 사건으로 남겼다.
**119개 사건**, 라벨 확신도 HIGH 106 / MEDIUM 52 / LOW 2건이며 사람 검수는 남아 있다.

사건 전체를 크기 내림차순(동률은 사건 ID 순)으로 배치하고, 각 주제의 양쪽 기사 수 차이
제곱합을 최소화했다. 배치 동률은 `SHA-256(independent-20260907-split-v1:eventId:split)`로 결정했다.
같은 사건·같은 원문은 주제가 달라도 분할을 넘지 않는다.

별도 감사 봉인에는 사전 계획·라벨링 근거·표본/분할 스크립트와 Java 코드 해시도 기록했다.

현재 설정의 저장된 Java 최종 멤버십에서 계산한 혼동행렬도 보고서의 precision/recall과 일치한다.

## 4. 오류 확인과 판정

평가 후에는 저장된 Java 출력만으로 아래 오류를 확인했다. 라벨·분할·임계값을 변경하거나
봉인 pack을 재평가하지 않았다.

현재 설정 holdout에서 놓친 26쌍은 울산포럼 10, 익산 간담회 5, 국가채무 전망 3,
브랜드가치 집계 2, 아이지 발표 2쌍이다. 아산 모빌리티·구미 대표단·관세 인터뷰·국민성장펀드는 각각 1쌍이다.

추출된 엔티티가 0이라는 사실은 원문에 공통 사건 단서가 없다는 뜻이 아니다.
울산포럼처럼 제목에 같은 행사명이 있는 사례도 있으며, 제목 조직 프로파일이 있는 기사는
160건 중 15건뿐이다. 엔티티·조직 인식과 사건 구분의 한계를 먼저 분류해야 한다.

사전 판정표에서 선택 설정의 **precision ≥0.90, recall <0.75**는 임베딩 **검토 착수** 구간이다.
자동 도입 결정은 아니다. 규칙 보정 후에도 낮은 recall이 유지되는지, 누락 30쌍 중 실제로
공통 제목·엔티티 단서가 없는 사례가 과반인지, 1,000건 성능 조건을 충족하는지는 아직 확인하지 않았다.
이번 selected holdout의 누락은 23쌍뿐이며, calibration 오류도 남아 있다.
전체 보류 기능 재판정은 사용자가 정한 4번 순서에서 이 결과와 함께 다룬다.

**1번 측정 절차는 완료, 품질 관문은 미통과**다. 다음 작업은 정상 실행 10회 비용 측정이며,
OpenAI 전환 전후 provider·model·단가를 구분한다. A11 1주 관찰과 나머지 보류 기능 감사는 이후다.
이 측정만으로 클러스터 최종 확정이나 전체 안정화 완료를 선언하지 않는다.
