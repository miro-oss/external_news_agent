# report-importance.v1

중요도는 선택한 관점의 의사결정 우선순위다. 산업의 인기도, 기사 길이, 긍정·부정 감성, 기업 유명세, 모델 자신감으로 점수를 정하지 않는다. directness, impact, urgency를 각각 독립적으로 0~3 또는 null로 판정한다.

| 축 | 0 | 1 | 2 | 3 | null |
|---|---|---|---|---|---|
| directness | 근거상 이 관점의 판단과 관련 없음 | 간접 배경이며 연결에 여러 미확인 가정이 필요 | 구체적인 업무 판단과 연결되지만 중간 전제 있음 | 이 관점의 생산·조달·인증·운영·실적 관찰 판단을 직접 변경 | 어떤 판단과 연결되는지 근거로 확인 불가 |
| impact | 연결돼도 의사결정 변경이 관측되지 않음 | 제한된 대상·범위의 확인 또는 준비 사항 | 제품·공정·프로젝트 수준의 일정·조건·자원 판단에 영향 | 명시된 공급·생산·투자·운영 제약이 핵심 결정에 큰 영향 | 효과의 범위·크기를 근거로 확인 불가 |
| urgency | 근거상 현재 확인·대응할 시급성이 없음 | 후속 발표를 관찰할 사항이며 임박한 일정 없음 | 명시된 일정·전환·확인 기회가 있어 준비 순서 검토 필요 | 즉시 적용·중단·임박한 마감 등으로 현재 판단 갱신 필요 | 행동 시점·기한의 근거 없음 |

- 0은 판정 결과다. null은 판정 불가다. 관련성 없는 기사라는 근거가 있으면 directness=0이며 basisClaimIds를 연결한다. 정보가 부족해서 관계를 모르면 directness=null이다.
- impact=3은 제목이나 계획만으로 부여하지 않는다. 핵심 업무에 큰 영향을 주는 범위·제약의 근거를 reason에 명시해야 한다.
- urgency=3은 "중요하다"는 이유만으로 부여하지 않는다. 현재 적용·가동 중단·기한의 명시된 근거가 필요하다. 날짜가 없다면 urgency=null을 우선 고려한다.
- 시급성의 평가 시점은 reportEndDate, 없으면 reportDate, 둘 다 없으면 findings.publishedAt의 가장 최근 날짜다. 사용자가 읽는 오늘이나 모델의 현재 날짜를 기준으로 삼지 않는다. 모든 기준 날짜가 없으면 "현재/임박/이번 주"를 확정하지 않고 urgency=null을 우선 사용한다.
- 원문의 "내일/내년"은 해당 기사의 publishedAt 기준이다. 이미 지난 기한을 리포트 기준 시점의 임박한 마감으로 평가하지 않는다. 이후의 실제 이행 여부가 없으면 그것을 watchItem으로 확인한다.
- novelty는 이번 입력에 이전 보고서 스냅샷이 없으므로 항상 null이다. 첫 기사, 최초 발표, NEW 표기가 기준선을 대신하지 않는다.
- 상충하는 근거로 핵심 판단을 확정할 수 없으면 영향·시급성 축을 null로 보류하고 확인할 조건을 제시한다.
- 점수와 정렬은 서버가 계산한다. directness 또는 impact가 null이면 unavailable이다. directness=0이면 low다. 그 외는 directness 0.4 + impact 0.4 + urgency 0.2의 가중평균이며 urgency=null이면 남은 가중치를 정규화한다. 2.25 이상 high, 1.25 이상 medium, 나머지 low다. 이 결과를 만들기 위해 축 점수를 역산하지 않는다.
