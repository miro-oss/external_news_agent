# report-importance.v6

DIRECT: 원문 사건·조건이 해당 관점 업무 자체다. CONDITIONAL: 원문 사건을 해당 업무로 연결하는 구체적인 미확인 중간 전제가 필요하다. BACKGROUND: 여러 전제가 필요한 배경이다. UNRELATED: 원문상 무관한 업무다. UNDETERMINED: 업무 연결을 판단할 근거 부족이다. 자료 부족은 중간 전제가 아니다. 관계 판단이 불가하면 UNRELATED가 아니라 UNDETERMINED다.

확인된 고객 공급 계약·조달 조건·공정 인증·설계 적용은 이행 결과가 미정이어도 해당 업무에 직접 연결될 수 있다. 업무 관계, 영향 범위, 행동 시점은 별개로 판단한다.

impact는 해당 관점 업무와 연결된 기사상 대상의 변화 범위다. 제공되지 않은 독자 회사 전체의 손익을 추정하는 축이 아니다. 업무 관련성과 별도로 원문의 적용 대상과 바뀌는 조건·일정·자원 또는 준비 범위를 찾고 아래 범주에 대조한다.
- CORE_CONSTRAINT: 핵심 대상의 실제 제약이 명시된다. 중요해 보이는 기업·산업이라는 이유는 해당하지 않는다.
- PROJECT_CHANGE: 특정 프로젝트의 조건·일정·자원 변경이 명시된다. 전체 기업의 손익이나 최종 이행 결과까지 알아야 하는 것은 아니다.
- LIMITED_PREPARATION: 제한된 대상의 준비가 명시된다. 상세 정보가 적다는 이유로 이 범주를 선택하지 않는다.
- NO_CHANGE: 해당 대상의 변경 없음이 명시된다. 변화에 관한 언급이 없는 경우와 다르다.
- UNDETERMINED: 업무 연결은 알지만 위 범주를 뒷받침할 변화·준비의 대상 또는 범위를 확인하지 못한다.

원문에 영향 대상과 변경 범위가 확인되면 정량 금액·비율 없이도 정성적으로 판정한다. 원문에 특정된 범위로만 판단하고 독자 조직 전체로 확대하지 않는다. 계획·전망은 범위가 구체적이어도 이미 실현된 효과로 바꾸지 않는다. 알려진 제한 대상의 변화와 규모 자체를 모르는 경우를 구분한다. 알려진 업무 관계만으로 영향 범주를 채우거나 미확인을 NO_CHANGE로 바꾸지 않는다.

urgency: IMMEDIATE=현재 즉시 적용·계속된 중단·실제 임박 마감, SCHEDULED_PREPARATION=준비 순서를 바꾸는 실제 일정, MONITOR=후속 이행 관찰, NOT_URGENT=명시된 시급하지 않음, UNDETERMINED=행동 시점 불명.

UNRELATED/UNDETERMINED는 work/condition=null이고 영향·시점도 미확인이다. 조건부 관계는 실제 사건→구체 업무의 미확인 전제를 condition에 쓴다. '미확인'이나 기사 재요약만으로 condition을 채우지 않는다. novelty=null.

점수는 서버가 계산한다. UNRELATED의 직접 관련성 0은 영향·시점 미확인이어도 낮음이다. 그 밖에 직접 관련성 또는 영향 미확인은 판단 보류다. 가중치와 등급 경계값은 유지한다. 낮은 점수나 보류 비율을 줄이려고 원문이 지원하지 않는 범주를 선택하지 않는다.
